# Vocabulary Learning

## Descripción

Pequeña aplicación para practicar y repasar vocabulario usando el fichero `vocabulario_b2.json`.

## Requisitos

- Python 3.8 o superior
- No hay dependencias externas obligatorias (si el script las necesita, añádelas en `requirements.txt`).

## Uso

1. Coloca `vocabulario_b2.json` en la misma carpeta que el script.
2. Ejecuta el script:

```bash
python Vocabulary_Learning.py
```

## Archivos principales

- `Vocabulary_Learning.py`: script principal.
- `vocabulario_b2.json`: fichero con el vocabulario.
- `README.md`: este archivo.
